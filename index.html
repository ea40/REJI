Digital Bridge developer documentation

Everything you need to build and deploy accessible learning media with synchronized Amharic captions, EthSL sign language, and inclusive career tools: start fast, scale reliably across low-bandwidth networks.

Use cases

Core deployment modules for ALX Savanna LMS
Savanna LMS Integration

Accessible Video Player (<db-player>)

Drop-in zero-dependency custom element for Savanna LMS. Features dual-stream synchronized EthSL sign language overlay, bilingual Amharic/English WebVTT captions, 5-speed playback cycling, and TalkBack live region screen reader support.

Launch Savanna Course Page →
Career Gateway

Inclusive Job Gateway (<db-job-card>)

Accessible job listings across Addis Ababa with disability accommodation tags, one-click Web Speech API audio synthesizers (tested at 200% zoom), and astronomical Ethiopian calendar conversions (ዓ.ም.).

Explore Career Gateway Feed →
Open Badges 3.0

Cryptographic Verifiable Credential

Employer verification portal checking W3C Verifiable Credentials with Ed25519 digital signatures. Features real-time anti-tamper detection, offline client-side crypto fallback, and accessible audio chime confirmation.

Verify Student Certificate →
Educator Tool

Amharic Caption Review Studio

Accessible web workstation for blind educators and linguists to inspect machine-translated Amharic cues, adjust timecode synchronization, and validate contrast ratios using full keyboard navigation.

Open Caption Studio →
Zero Dependencies

Standalone Proof (blank.html)

Single-tag <script> embed proving <db-player> functions completely isolated from Savanna LMS, firing telemetry CustomEvents (progress, captions, rate) to the host window.
